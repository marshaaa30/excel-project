EMPLOYEE DATA ANALYSIS

 Project Overview

This project analyzes employee data to understand workforce distribution, salary patterns, departmental performance, employee experience, and recruitment trends. The analysis was performed using Excel and presented through an interactive dashboard.

 Dataset Description

The dataset contains 500 employee records with information related to employees, including department, salary, age, experience, joining date, and manager status.

Tools Used

* Microsoft Excel 
* Excel Functions 
* PivotTables & PivotCharts
* Slicers 

Data Cleaning

The following data-cleaning steps were performed before creating the dashboard:

* Checked the dataset for missing values.
* Removed duplicate records where applicable.
* Corrected inconsistent data formats.
* Converted date fields into a consistent date format.
* Checked numerical columns such as salary, age, and experience.
* Standardized department and categorical values.
* Verified that employee records contained valid and usable information.
* Created calculated fields where required for analysis.

Data cleaning was important because inaccurate or inconsistent data could affect PivotTables, calculations, charts, and dashboard findings.

Business Questions

1. How many employees are there in each department?
2. What is the average salary in each department?
3. How many managers and non-managers are there?
4. How has employee joining volume changed over the years?
5. How are employees distributed across different age and salary ranges?

Dashboard

 Key Findings

* The dataset contains 500 employees.
* IT has the highest number of employees, with 110 employees.
* The overall average salary is approximately ₹170,634.
* Marketing has the highest departmental average salary at approximately ₹177,127.
* There are 257 managers and 243 non-managers.
* The 40–49 age group contains the largest number of employees.
* The ₹1.5–2 lakh salary range contains the largest number of employees.
* The highest recorded salary is approximately ₹293,410.
* Most employees have more than 10 years of experience.

 Recommendations

* Review workforce distribution across departments to identify staffing requirements.
* Analyze salary differences between departments and experience levels.
* Monitor the manager-to-employee ratio for effective workforce planning.
* Use employee joining trends to improve future recruitment planning.
* Develop training and career-development programs based on employee experience.
